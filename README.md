# dsh-fish-qq

给你的 DeepSeek Harness 接一只 **QQ 群宠物**：按人设说话、有记忆、会长性格，还能在你忙的时候替你应两声。

她通过 **NapCat（OneBot 11）** 收发 QQ 消息，自己不是协议端。

## 她能做什么

| 场景 | 行为 |
|---|---|
| 你 @ 她 | 必回，人设语气 |
| 你普通发言 | 判断是不是在叫她/吩咐她，是才接 |
| 群里其他人 | **一律不理**（不会替你抢话，也不会替别人干活） |
| 每 60 分钟 | 判断群热不热；热则出摘要、算你的兴趣分；够分就私信你 |
| 你私信回「你」 | 用**你的语气**替你在群里应 1–2 句，30 分钟自动停 |
| 你私信回「我」 | 助攻模式：你聊你的，她一波最多补两句，2 小时自动停 |
| 你自嘲/说丧气话 | 不许附和，要护你 |
| 你下令（"咬他""去怼"） | 不反问细节，自己找对象，直接回一句 @ 对方 |

她还会**成长**：每积累 20 条群聊，从聊天里提炼最多 2 条新习惯/口味/关系，写进成长档案——之后说话会带着这些长出来的东西。

## 前置条件（躲不掉）

1. **NapCat**（或任何 OneBot 11 协议端），用一个 QQ 号登录，开一个 WebSocket 服务（默认 `ws://127.0.0.1:3001`）
2. 一个 **DeepSeek API key**
3. 那个 QQ 号**已经在目标群里**

> ⚠️ NapCat 是第三方协议端，登录你的 QQ 号属于违反 QQ 用户协议的行为，有封号风险。建议用小号。本项目只是消息桥，不承担账号风险。

## 安装

```sh
dsh plugin --profile <你的profile> add ./dsh-fish-qq
```

然后在 **插件 → dsh-fish-qq** 里填配置。

## 配置项

| 键 | 说明 |
|---|---|
| `enabled` | 打开才开始跑（填完配置再开） |
| `napcatUrl` | NapCat 的 OneBot WebSocket 地址 |
| `groupId` | 群号 |
| `ownerQQ` | 你的 QQ 号（只有这个号会被服务） |
| `selfQQ` | 机器人 QQ（留空自动读） |
| `apiKey` / `apiBase` | 模型凭据（key 存为密文） |
| `persona` | 人设提示词 |
| `ownerProfile` | 关于你：怎么说话、在意什么 |
| `chatSamples` | 你的聊天样本，代水时模仿语气用（**这段决定像不像你**） |
| `memes` | 群里的梗：谐音、人物、玩法 |
| `intervalMin` | 巡检间隔，默认 60 |
| `hotMin` | 一小时内多少条算热，默认 4 |
| `interestMin` | 兴趣分达到多少才私信你，默认 4 |
| `quietWhenOwnerActiveMin` | 你多少分钟内有发言就跳过巡检，默认 15 |
| `workWindowEnabled` | 只在工作时间窗口内巡检和私信，默认开 |
| `workStart` / `workEnd` | 工作时间窗口（本地时间，支持跨零点），默认 `07:30`–`23:30`；窗口外保持安静，只有你 @ 她才会应 |

## 数据在哪

`~/.dsh-fish-qq/`

- `memory.json` — 滚动对话记忆（最近 300 条）
- `growth.md` — 她的成长档案
- `fish-qq.log` — 每次判断、每次发言都记在这里

删掉 `growth.md` 她就"失忆重生"，方便重新养。

## 已知限制

- 只支持一个群、一个主人。
- 每轮判断都是一次模型调用，热闹群会烧 token；`hotMin` 和 `intervalMin` 是主要闸门。
- 没有内置 QQ 登录界面：登录由 NapCat 负责，本插件只连它的 WebSocket。
